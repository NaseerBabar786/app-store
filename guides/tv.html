How to install our apps on a TV

For Google TV, Android TV (Chromecast, Sony, TCL, Hisense, Philips…) and Amazon Fire TV. You only need the TV remote.

Download this guide (PDF)Phone guide

Step 1: Get the Downloader app (once)

  1. On the TV home screen, open Search (or the Apps / Google Play store) and search for Downloader. Pick the one by AFTVnews with the orange icon.
  2. Press Install, then Open. Allow it to use storage if it asks.

Step 2: Allow Downloader to install apps (once)

  1. Google TV / Android TV: go to Settings › System › About, scroll to Android TV OS build and press OK 7 times until it says you are a developer.
  2. Then go to Settings › Apps › Security & restrictions › Unknown sources and turn on Downloader.
  3. Fire TV: Settings › My Fire TV › Developer options › Install unknown apps and turn on Downloader. (If Developer options is missing: Settings › My Fire TV › About, press OK on the device name 7 times.)

Step 3: Install App Bazaar

  1. Open Downloader. In the address box type:
    tv.bulkbazaar.ca/bazaar
    and press Go.
  2. When the download finishes, press Install. If Play Protect warns you, choose Install anyway (or More details › Install anyway).
  3. Press Open. App Bazaar now sits in your TV's apps list. You can delete the downloaded file when Downloader offers it.

Step 4: Install any of our apps from App Bazaar

  1. Open App Bazaar. It opens on TV apps. Move with the arrows on the remote; a yellow ring shows where you are.
  2. Go to an app's Install button and press OK. (Press OK on the picture to read about the app first.)
  3. The first time only, the TV asks to allow App Bazaar to install apps. Press Open settings, turn on App Bazaar, then press Back. The install continues by itself.
  4. Press Install on the TV's screen (and Install anyway if Play Protect asks), then Open.

Step 5: Keep apps up to date

  1. Open App Bazaar now and then. Apps with a newer version show Update, and the Updates tab lists them all. Press Update, then Install.
  2. New apps added to App Bazaar appear in the app by themselves.

If something goes wrong

  1. "There was a problem parsing the package": the download was cut off. Download it again.
  2. "App not installed": uninstall the old copy (Settings › Apps), then install again.
  3. An app didn't update: Settings › Apps › the app › Force stop, then open it again.
All our apps are free. They come from App Bazaar, not Google Play, so Play Protect may show a warning; that is normal for apps installed this way.
