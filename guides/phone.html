How to install our apps on an Android phone

For Android phones and tablets (Samsung, Google Pixel, Motorola, Xiaomi and others). iPhones can't install these apps.

Download App BazaarThis guide as PDFTV guide

Step 1: Download App Bazaar

  1. On your phone, open Chrome and go to apps.bulkbazaar.ca
  2. Tap App Bazaar, then Install. If Chrome asks whether to keep the file, tap Download anyway.

Step 2: Install it

  1. When the download finishes, tap Open (or open it from Files › Downloads).
  2. If the phone says Chrome can't install apps, tap Settings, turn on Allow from this source, and go back.
  3. Tap Install. If Play Protect warns you, tap More details › Install anyway. Then tap Open.

Step 3: Install any of our apps from App Bazaar

  1. Open App Bazaar. It opens on Phone apps; tap All apps to see everything.
  2. Tap Install on the app you want. Tap the picture first to read about it.
  3. The first time only, Android asks to allow App Bazaar to install apps. Tap Open settings, turn on Allow from this source, and go back. The install continues by itself.
  4. Tap Install (and Install anyway if Play Protect asks), then Open.

Step 4: Keep apps up to date

  1. Apps with a newer version show Update in App Bazaar, and the Updates tab lists them. Tap Update, then Install.
  2. New apps we add to App Bazaar appear in the app by themselves.

If something goes wrong

  1. "App not installed": uninstall the old copy (hold its icon › Uninstall), then install again.
  2. "Problem parsing the package": the download was cut off. Download it again on Wi-Fi.
  3. Samsung "Auto Blocker" is on: Settings › Security and privacy › Auto Blocker, turn it off while installing.
All our apps are free. They come from App Bazaar, not Google Play, so Play Protect may show a warning; that is normal for apps installed this way.
